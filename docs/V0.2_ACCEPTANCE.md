# V0.2 acceptance criteria

## Engine

- [x] Synthetic regression suite is green.
- [x] Greeting does not count as a buried business message.
- [x] Informational update does not receive an unnecessary CTA warning.
- [x] Recommendation/request/change messages do receive a CTA warning when action is absent.
- [x] Vague timing or certainty can be surfaced.
- [x] Subject review is optional at engine level and active in the Salesforce component.
- [x] Generic subjects are surfaced.
- [x] Action requests without timing are surfaced as informational guidance.
- [x] Distinct supporting points are not falsely labeled as overlapping in the reference cases.
- [x] Safe block actions preserve all non-target paragraphs.

## Salesforce UX

These remain unverified until deployment to a real Salesforce org.

- [ ] Component deploys as a screen record action.
- [ ] Component renders on Contact.
- [ ] Component renders on Lead.
- [ ] Component renders on Account.
- [ ] Component renders on Opportunity.
- [ ] Component renders on Case.
- [ ] Review-first works without a server call.
- [ ] Live Coach runs after a typing pause.
- [ ] Auto intent is visible to the user.
- [ ] User can override message type.
- [ ] Findings can be dismissed locally.
- [ ] Safe suggestions can be applied.
- [ ] Manual suggestions return focus to the editor.
- [ ] Subject and body hand off to Salesforce Email.

## Privacy

- [x] No Apex persistence.
- [x] No external network request.
- [x] No raw email telemetry.
- [x] No employee score or ranking.

## Release gate

V0.2 can be tagged only after:

1. CI is green;
2. one real Salesforce Developer Edition/sandbox deployment succeeds;
3. Contact smoke test passes end to end;
4. any critical content-loss or composer-handoff defect is fixed.
