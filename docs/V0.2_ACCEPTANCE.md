# V0.2 acceptance criteria

## Engine

- [ ] Synthetic regression suite is green.
- [ ] Greeting does not count as a buried business message.
- [ ] Informational update does not receive an unnecessary CTA warning.
- [ ] Recommendation/request/change messages do receive a CTA warning when action is absent.
- [ ] Vague timing or certainty can be surfaced.
- [ ] Subject review is optional at engine level and active in the Salesforce component.
- [ ] Generic subjects are surfaced.
- [ ] Action requests without timing are surfaced as informational guidance.
- [ ] Distinct supporting points are not falsely labeled as overlapping in the reference cases.
- [ ] Safe block actions preserve all non-target paragraphs.

## Salesforce UX

- [ ] Component deploys as a screen record action.
- [ ] Component renders on Contact.
- [ ] Component renders on Lead.
- [ ] Component renders on Account.
- [ ] Component renders on Opportunity.
- [ ] Component renders on Case.
- [ ] Review-first works without a server call.
- [ ] Live Coach runs after a typing pause.
- [ ] Auto intent is visible to the user.
- [ ] User can override message type.
- [ ] Findings can be dismissed locally.
- [ ] Safe suggestions can be applied.
- [ ] Manual suggestions return focus to the editor.
- [ ] Subject and body hand off to Salesforce Email.

## Privacy

- [ ] No Apex persistence.
- [ ] No external network request.
- [ ] No raw email telemetry.
- [ ] No employee score or ranking.

## Release gate

V0.2 can be tagged only after:

1. CI is green;
2. one real Salesforce Developer Edition/sandbox deployment succeeds;
3. Contact smoke test passes end to end;
4. any critical content-loss or composer-handoff defect is fixed.
